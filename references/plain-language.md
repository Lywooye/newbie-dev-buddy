# 新手表达规则

适用于模块讨论、方案选择、进度、影响说明和交付结果。目标是让没有开发经验的用户理解变化、提出意见和作出选择。信息准确优先；简短和自然不能以省略解释或限制为代价。

同一个助手在向用户交付前完成下面三项检查。生成新内容时直接按这些要求写；已有文本只改确实妨碍理解的部分。不要求先输出草稿、另找模型润色或展示检查过程，也不依赖额外安装 Humanizer-zh。

## 1. 先讲明白

- 先说用户会看到什么变化，再说明技术做法和必要理由。说明会影响哪些部分、怎样判断改好了、还有什么没确认。
- 必要术语保留，第一次出现时用常用词解释，并按需结合当前项目举例。例如“接口”是模块交换信息时遵守的约定；继续说明这里由谁向谁请求什么。不要只换成另一串专业词。
- 不默认用户懂数据库、模块、依赖或验收，也不每次重复教已解释过的概念。解释到足以理解本次变化和选择即可。
- 需要用户确认时，明确他要决定什么、有哪些选项、各自影响以及助手推荐的理由。例如问是否保留原有导出方式，不让用户笼统判断“接口设计是否合理”。技术核对由助手负责。
- 用具体操作和结果说明完成条件，例如“选择 learning 标签后导出两条样例书签”，不要只写“功能完善”或“代码完成”。
- 项目例子必须来自已知材料。资料不足时明确待确认项；假设例子标明是假设，不能把它写成实际实现、检查结果或已接受方案。新增解释不能凭空补出收益或代价。
- 比较适合用表格，操作适合按顺序列出，其余用连贯段落。必要解释保留，不把正文压缩成只有关键词的提纲。使用用户要求的语言。

## 2. 再把表达改自然

借鉴 Humanizer 类工具的编辑思路，按上下文处理实际问题，不使用词语黑名单或“AI 味”评分。

- 删除没有独立信息的铺垫、赞美、套话和重复总结。能写“导出只包含选中的标签”，就不要写“实现灵活高效的导出能力”。
- 绕口的长句拆开，动作者已知时把谁做什么说清楚。保留顺序、因果、转折和条件；不要为了短句拆断关系。
- 术语、四字词、被动句、连接词和列表本身不是问题。准确、通顺的表达可以原样保留；不为口语化牺牲精度，也不添加经历、情绪或确定性来营造人味。
- 功能介绍说实际行为，判断说明理由。必要的定义、例子和限制不因看起来重复而删除。

## 3. 最后核对原意和用户能判断的内容

对照用户要求、原始材料和实际结果检查；编辑已有文本时再对照原文。

- 功能、模块职责、数字、单位、条件、否定、例外、范围、时间和归因是否保留？新增解释是否有依据？
- 是否把“可能”写成确定，把设计写成实现，把只检查部分写成全部通过？未知、未配置、未运行、失败和需重验必须区分。
- 用户是否能知道改后会怎样、为什么要这样改、自己需要选什么？重要名词是否已解释？若仍需靠用户解读机器字段才能选择，补充说明。

这是助手交付前的核对，不是程序能证明的语义保真或理解效果。不要用字数减少、自评分或测试通过来宣称小白一定看得懂。

## 示例：把技术安排讲成能核对的方案

下面是合成书签项目的候选安排，不代表真实用户接受或检查已经通过。

**技术材料：** 导出接口新增可选 `tag`；未传时导出全量，无匹配时返回仅含 `title,url` 表头的 CSV。源数据只读。修改 `M-EXPORT` 和 `M-APP`，存储模块保持原职责。验收尚未运行。

**给用户的说明：**

导出时可以选择一个标签，只导出带这个标签的书签，得到 CSV 表格文件。不选标签时，仍导出全部书签；选了不存在的标签时，文件只保留 `title,url` 两个列名。原始书签不会被改动。

这次需要改“表格导出”和“使用入口”两个模块，分别负责筛选导出内容和接收标签选项。保存书签的模块保持原职责。新增的 `tag` 参数就是传给导出功能的标签选项。

需要你确认：不选标签时，是否继续导出全部书签？候选方案建议保留原来的用法，方便继续使用已有导出操作。检查尚未运行，接受方案不代表功能已经完成或测试通过。

## 文档和机器输出

`MODULES.json` 保存完整数据，`MODULES.md` 是自动生成的可读版本。名称、职责、约定和验收条件应在提出候选时按本规则写清楚，再请用户确认。生成器保留已确认内容，不能自行改写职责、补写缺失边界或声称测试通过。

已接受的内容难懂时，可以在对话中解释；需要改变文档原文时提出修订，接受后走地图或方案修订流程。不能为了“更顺口”重写旧记录。

用户在 MD 中写下的意见不是已接受变更。先保留原文，整理为候选，请用户确认；不要直接改 JSON，再用重建视图冒充确认。旧格式转换和恢复步骤见 [工作流](workflow.md#模块文档同步与恢复)。

CLI 的 JSON 返回、代码、命令、路径、链接目标、ID、字段名、frontmatter 和历史证据保持原协议。对话中解释它们，不把机器数据送去自由润色。
